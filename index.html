01 / THE CONCEPT

Logistics is more than
finding a short road.

Routing combines locations, road connections, travel costs, delivery priorities, and changing conditions to recommend a practical journey.

⌁

Turn a complex network into a clear decision.

A routing system represents places as nodes and roads as edges. An algorithm searches those connections to find a route that fits the chosen objective.

04 / ALGORITHM NOTES

Same network.
Different strategies.

Run each algorithm on the same start and destination to compare its chosen route and search behavior.

ALGORITHM 01

Dijkstra

Finds the minimum-total-weight path when road weights are non-negative. Useful when edge weights represent distance, time, or cost.

Goal: lowest total weight
ALGORITHM 02

Breadth-First Search

Finds a path with the fewest edges in an unweighted graph. It does not necessarily minimize the sum of road weights.

Goal: fewest road segments
ALGORITHM 03

A* Search

Uses a heuristic estimate toward the destination to guide exploration. In this demo, the heuristic is based on grid distance.

Goal: guided path search
Academic note: This lab demonstrates graph-search behavior on a small synthetic network. It is not a live map, GPS navigation service, traffic prediction system, or a full multi-vehicle optimization solver.
